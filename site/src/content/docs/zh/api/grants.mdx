Grants 管理端点维护决定谁能调用命令的 [grants](/zh/grants/)。它们都需要有效的
`slash_session` cookie 和 **org owner** 角色（`org_members.role = 'owner'`）——
其他任何人在 fail-closed 下都会收到 `403`。grant 创建后不可变：修改意味着删除后
重建。

## GET `/api/grants`

列出调用者组织里的每个 grant，并解析出 subject 和授权人名字。

```sh
curl -b cookies.txt https://slash.example.com/api/grants
```

成功：`200 OK`，带一个数组。

```json
[
  {
    "id": "3b6d4f12-9a41-4f88-a1c5-8a4d4b6e9f10",
    "subject_type": "team",
    "subject_id": "cb50f1d6-7a11-44d7-b45e-9c158b8e7774",
    "subject_name": "eng",
    "scope": "command",
    "repository": "acme/widgets",
    "command": "deploy",
    "permission": "write",
    "effect": "allow",
    "granted_by": "1165fc2c-64f4-49f6-b77c-15317cf59fb8",
    "granted_by_name": "Release Operator"
  }
]
```

| 状态 | 含义 |
| --- | --- |
| `200` | Grants 已列出 |
| `401` | 无有效会话 |
| `403` | 调用者不是 org owner |
| `500` | 列出失败 |

## POST `/api/grants`

创建一条 grant。请求体使用 camelCase：

```json
{
  "subjectType": "team",
  "subjectId": "cb50f1d6-7a11-44d7-b45e-9c158b8e7774",
  "scope": "command",
  "repository": "acme/widgets",
  "command": "deploy",
  "permission": "write",
  "effect": "allow"
}
```

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `subjectType` | 是 | `user` 或 `team` |
| `subjectId` | 是 | `users.id` 或 `teams.id`；必须属于该 org |
| `scope` | 是 | `org`、`repository` 或 `command` |
| `repository` | scope 为 `repository` 或 `command` 时 | `owner/repo` |
| `command` | scope 为 `command` 时 | 命令名 |
| `permission` | 是 | `read`、`write` 或 `admin` |
| `effect` | 否 | `allow`（默认）或 `deny` |

成功：`200 OK`。

```json
{
  "id": "3b6d4f12-9a41-4f88-a1c5-8a4d4b6e9f10"
}
```

| 状态 | 含义 |
| --- | --- |
| `200` | Grant 已创建 |
| `401` | 无有效会话 |
| `403` | 调用者不是 org owner |
| `409` | 已存在完全相同的 grant（含 org-scope 重复） |
| `422` | 校验失败（subject/scope/字段错误，或 subject 不在 org） |
| `500` | 创建失败 |

## DELETE `/api/grants/{id}`

删除一条 grant，限定在调用者的 org 内（其他 org 的 grant 不会被找到）。

```sh
curl -b cookies.txt -X DELETE \
  https://slash.example.com/api/grants/3b6d4f12-9a41-4f88-a1c5-8a4d4b6e9f10
```

成功为 `204 No Content`。未知 grant 返回 `404`；非 owner 返回 `403`。

## GET `/api/org/members`

列出 org 的 users 和 teams，供 grant subject 选择。

```sh
curl -b cookies.txt https://slash.example.com/api/org/members
```

成功：`200 OK`。

```json
{
  "orgId": "b07dc85d-d18c-42fa-9a58-055d9f32801c",
  "users": [
    { "id": "1165fc2c-64f4-49f6-b77c-15317cf59fb8", "name": "Release Operator" }
  ],
  "teams": [
    { "id": "cb50f1d6-7a11-44d7-b45e-9c158b8e7774", "name": "eng" }
  ]
}
```

与其他 grants 端点相同的状态码（仅 owner）。
