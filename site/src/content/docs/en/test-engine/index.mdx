Test Engine turns test history into a continuous quarantine loop. Your CI runs
the tests; Slash receives the results, detects flaky behavior, and records the
disposition that the next CI run should apply.

Slash never executes repository code. It remains the control plane while your
existing CI system remains the execution plane.

## What you can do

- Collect normalized JSON, JUnit XML, Cargo libtest JSON, or Vitest results.
- Browse suites, tests, executions, pass rates, and recent failures.
- Detect tests that fail and later pass within a rolling seven-day window.
- Automatically mute flaky tests so they continue to run without blocking a
  pull request.
- Manually enable, mute, or skip a test.
- Query the current quarantine list before a CI run applies its final result.
