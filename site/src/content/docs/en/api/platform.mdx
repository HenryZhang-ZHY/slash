These endpoints support the GitHub App control plane and server operations.
They do not use the browser session or collection-token authentication used by
the other API surfaces.

## POST `/webhook`

Receives GitHub App webhook deliveries. Configure this as the GitHub App's
webhook URL:

```text
https://slash.example.com/webhook
```

Required headers:

| Header | Value |
| --- | --- |
| `Content-Type` | `application/json` |
| `X-GitHub-Event` | GitHub event name, such as `issue_comment` |
| `X-GitHub-Delivery` | Unique GitHub delivery GUID |
| `X-Hub-Signature-256` | `sha256=<hex HMAC-SHA256>` over the exact request body |

The HMAC key is the webhook secret read at startup from the file pointed at by
`SLASH_WEBHOOK_SECRET_PATH`. Slash verifies the raw request bytes,
then durably inserts the delivery before acknowledging it. JSON parsing and
GitHub API work happen asynchronously after the response.

| Status | Meaning |
| --- | --- |
| `200` | Delivery was stored, or the delivery GUID was already stored |
| `400` | Event, delivery, or accepted content-type header is missing or invalid |
| `403` | Signature is missing, malformed, or does not match |
| `413` | Body exceeds the global 5 MiB limit |
| `500` | The delivery could not be stored |

Redelivering the same `X-GitHub-Delivery` value is idempotent and returns
`200` without inserting a second delivery.

## GET `/healthz`

An unauthenticated liveness probe.

```sh
curl https://slash.example.com/healthz
```

Success: `200 OK` with a plain-text body:

```text
ok
```

The handler does not query Postgres or GitHub. It indicates that the HTTP
process can serve requests, not that downstream dependencies are healthy.

## GET `/metrics`

Returns the unauthenticated Prometheus text exposition generated by the
in-process metrics registry.

```sh
curl https://slash.example.com/metrics
```

Important metric families include:

| Metric | Purpose |
| --- | --- |
| `slash_webhook_deliveries_total{event,outcome}` | Webhook intake outcomes |
| `slash_webhook_handler_seconds{outcome}` | Webhook handler latency |
| `slash_deliveries_pending` | Pending durable deliveries |
| `slash_deliveries_oldest_pending_age_seconds` | Age of the oldest pending delivery |
| `slash_invocations{status}` | Invocation lifecycle counts |
| `slash_invocations_max_dispatched_age_seconds` | Oldest dispatch awaiting a run ID |
| `slash_correlation_total{path}` | Dispatch/run correlation path |
| `slash_dispatch_failures_total{class}` | Dispatch failure classes |
| `slash_command_catalog_loads_total{outcome,stage}` | Command catalog load outcomes |
| `slash_test_engine_uploads_total{kind,outcome}` | Test ingestion outcomes |

Protect this endpoint at the network or reverse-proxy layer if metrics should
not be public on your deployment.
