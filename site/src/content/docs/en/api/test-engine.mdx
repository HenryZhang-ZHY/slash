All management endpoints require a valid `slash_session` cookie. Suite and
test data is scoped to the account that owns the suite. Resources owned by a
different account are reported as `404 Not Found` rather than revealing their
existence.

IDs in paths are UUIDs. Test Engine JSON fields use `snake_case`.

## GET `/api/test-engine/suites`

Lists the authenticated account's suites and aggregate execution counts.

```sh
curl -b cookies.txt \
  https://slash.example.com/api/test-engine/suites
```

Success: `200 OK` with an array.

```json
[
  {
    "id": "0e1ef24a-927f-4094-bdaf-477e17c123b8",
    "suite_key": "ci-test",
    "owner": "acme",
    "repo": "checkout",
    "total_tests": 42,
    "muted": 2,
    "skipped": 1,
    "run_count": 18,
    "execution_count": 756,
    "passed_executions": 718,
    "failed_executions": 30,
    "skipped_executions": 6,
    "errored_executions": 2,
    "average_duration_ms": 83.4,
    "last_captured": "2026-08-12T04:00:00+00:00"
  }
]
```

`average_duration_ms` and `last_captured` are `null` until execution data is
available. Storage failures return `500`.

## POST `/api/test-engine/suites`

Creates a suite, or reuses the matching suite when it is already owned by the
current account. Create the collection token separately after the suite exists.

```sh
curl -b cookies.txt \
  -H "Content-Type: application/json" \
  -d '{"owner":"acme","repo":"checkout","suite_key":"ci-test"}' \
  https://slash.example.com/api/test-engine/suites
```

All three fields are required, trimmed, and limited to 255 bytes.

Success: `201 Created`.

```json
{
  "suite": {
    "id": "0e1ef24a-927f-4094-bdaf-477e17c123b8",
    "suite_key": "ci-test",
    "owner": "acme",
    "repo": "checkout",
    "total_tests": 0,
    "muted": 0,
    "skipped": 0,
    "run_count": 0,
    "execution_count": 0,
    "passed_executions": 0,
    "failed_executions": 0,
    "skipped_executions": 0,
    "errored_executions": 0,
    "average_duration_ms": null,
    "last_captured": null
  }
}
```

| Status | Meaning |
| --- | --- |
| `201` | Suite available |
| `401` | No valid session |
| `409` | A different account owns the matching suite |
| `422` | A required field is empty or too long |
| `500` | Suite persistence failed |

## GET `/api/test-engine/suites/{id}/tests`

Lists all tests in an owned suite, including their current disposal state,
latest run metadata, and aggregate execution counts.

```sh
curl -b cookies.txt \
  https://slash.example.com/api/test-engine/suites/0e1ef24a-927f-4094-bdaf-477e17c123b8/tests
```

Success: `200 OK` with an array.

```json
[
  {
    "id": "df5a68b4-bf9f-4745-a320-a7cd39b59249",
    "name": "checkout::completes_order",
    "state": "enabled",
    "state_source": "monitor",
    "state_reason": "failure-free reconciliation window",
    "state_changed_by_user_id": null,
    "state_changed_at": "2026-08-12T03:55:00+00:00",
    "file": "tests/checkout.rs",
    "line_no": 42,
    "labels": [],
    "owner_team_ids": [],
    "created_at": "2026-08-12T03:00:00+00:00",
    "updated_at": "2026-08-12T04:00:00+00:00",
    "last_status": "passed",
    "last_captured": "2026-08-12T04:00:00+00:00",
    "last_run_ref": "build/1842",
    "last_ci_provider": "buildkite",
    "execution_count": 18,
    "passed_count": 17,
    "failed_count": 1,
    "skipped_count": 0,
    "errored_count": 0,
    "average_duration_ms": 91.2
  }
]
```

`state_source` is `default`, `manual`, or `monitor`. The optional state reason
and actor identify the current decision; latest-run and average fields may
also be `null`. An unknown or unowned suite returns `404`; storage failures
return `500`.

## GET `/api/test-engine/suites/{id}/runs`

Returns one page of the owned suite's runs, newest first, with execution totals
for each run.

| Query parameter | Default | Behavior |
| --- | --- | --- |
| `limit` | `100` | Clamped to `1..200` |
| `offset` | `0` | Negative values become `0` |

```sh
curl -b cookies.txt \
  "https://slash.example.com/api/test-engine/suites/0e1ef24a-927f-4094-bdaf-477e17c123b8/runs?limit=25&offset=0"
```

Success: `200 OK`.

```json
{
  "total": 18,
  "limit": 25,
  "offset": 0,
  "items": [
    {
      "id": "68e4a959-c699-4e32-9164-a4500ecfe26d",
      "run_ref": "build/1842",
      "ci_provider": "buildkite",
      "invocation_id": null,
      "started_at": "2026-08-12T03:59:00+00:00",
      "finished_at": null,
      "last_captured": "2026-08-12T04:00:00+00:00",
      "execution_count": 42,
      "passed_count": 39,
      "failed_count": 2,
      "skipped_count": 1,
      "errored_count": 0,
      "total_duration_ms": 3487
    }
  ]
}
```

`total_duration_ms` is the sum of the durations reported by the run's test
executions. `last_captured` is `null` for a run with no executions. An unknown
or unowned suite returns `404`; storage failures return `500`.

## GET `/api/test-engine/runs/{id}/executions`

Returns one page of the tests captured in a run owned by the current account.
It uses the same bounded `limit` and `offset` behavior as the run list.

```sh
curl -b cookies.txt \
  "https://slash.example.com/api/test-engine/runs/68e4a959-c699-4e32-9164-a4500ecfe26d/executions?limit=100&offset=0"
```

Success: `200 OK`.

```json
{
  "total": 42,
  "limit": 100,
  "offset": 0,
  "items": [
    {
      "id": "f8789438-fb99-45f6-a374-1335593264d1",
      "test_id": "df5a68b4-bf9f-4745-a320-a7cd39b59249",
      "test_name": "checkout::completes_order",
      "test_state": "enabled",
      "file": "tests/checkout.rs",
      "line_no": 42,
      "status": "passed",
      "duration_ms": 87,
      "stack": null,
      "captured_at": "2026-08-12T04:00:00+00:00"
    }
  ]
}
```

An unknown run or a run outside the account's owned suites returns an empty
page. Storage failures return `500`.

Returns one page of recent execution history for a test owned by the current
account.

| Query parameter | Default | Behavior |
| --- | --- | --- |
| `limit` | `100` | Clamped to `1..200` |
| `offset` | `0` | Negative values become `0` |

```sh
curl -b cookies.txt \
  "https://slash.example.com/api/test-engine/tests/df5a68b4-bf9f-4745-a320-a7cd39b59249/executions?limit=25&offset=0"
```

Success: `200 OK`.

```json
{
  "total": 18,
  "limit": 25,
  "offset": 0,
  "items": [
    {
      "id": "f8789438-fb99-45f6-a374-1335593264d1",
      "status": "passed",
      "duration_ms": 87,
      "stack": null,
      "captured_at": "2026-08-12T04:00:00+00:00",
      "run_id": "68e4a959-c699-4e32-9164-a4500ecfe26d",
      "run_ref": "build/1842",
      "ci_provider": "buildkite",
      "started_at": "2026-08-12T03:59:00+00:00",
      "finished_at": "2026-08-12T04:01:00+00:00",

```

Storage failures return `500`. A test outside the account's owned suites is
not included in results.

## PATCH `/api/test-engine/tests/{id}/state`

Changes a test's disposal state.

```sh
curl -b cookies.txt -X PATCH \
  -H "Content-Type: application/json" \
  -d '{"state":"muted","reason":"known provider instability"}' \
  https://slash.example.com/api/test-engine/tests/df5a68b4-bf9f-4745-a320-a7cd39b59249/state
```

Allowed state values are `enabled`, `muted`, and `skipped`. `reason` is an
optional string. The change is recorded as a manual decision with the current
user as actor; automatic flaky reconciliation does not overwrite it.

Success: `200 OK`.

```json
{
  "state": "muted"
}
```

| Status | Meaning |
| --- | --- |
| `200` | State changed |
| `404` | Test is unknown or not owned by the account |
| `409` | The state update lost a concurrent change |
| `422` | The requested state is unsupported |
| `500` | Ownership lookup or update failed |

## GET `/api/test-engine/suites/{id}/tokens`

Lists non-secret token metadata for an owned suite. Raw credentials are never
returned by this endpoint.

```json
[
  {
    "id": "2b914582-17c3-42c5-b9e8-439816360a3e",
    "name": "Buildkite production",
    "status": "active",
    "created_at": "2026-08-22T06:00:00+00:00",
    "expires_at": null,
    "last_used_at": "2026-08-22T06:05:00+00:00",
    "revoked_at": null
  }
]
```

Success is `200`. Unknown or unowned suites return `404`; storage failures
return `500`. `status` is `active`, `expired`, or `revoked`. `expires_at` is
`null` for a token that never expires.

## POST `/api/test-engine/suites/{id}/tokens`

Issues a new show-once collection token for an owned suite. Existing tokens
remain active, so separate CI collectors can use independently named
credentials and rotation does not interrupt uploads.

```sh
curl -b cookies.txt -X POST \
  -H "Content-Type: application/json" \
  -d '{"name":"Buildkite production","expires_at":null}' \
  https://slash.example.com/api/test-engine/suites/0e1ef24a-927f-4094-bdaf-477e17c123b8/tokens
```

`name` is required, trimmed, and limited to 100 characters. `expires_at` is
either `null` for no expiry or a future RFC 3339 timestamp. Omitting
`expires_at` also creates a non-expiring token.

Success: `201 Created`.

```json
{
  "id": "2b914582-17c3-42c5-b9e8-439816360a3e",
  "name": "Buildkite production",
  "token": "new-collection-token-value",
  "expires_at": null
}
```

Copy the raw token from this response immediately; Slash stores only its hash
and cannot display it again. Unknown or unowned suites return `404`; invalid
names or expiration times return `422`; issuance failures return `500`.

## DELETE `/api/test-engine/suites/{suite_id}/tokens/{token_id}`

Revokes one collection token by the metadata id returned by the list endpoint.
The raw secret is not required.

```sh
curl -b cookies.txt -X DELETE \
  https://slash.example.com/api/test-engine/suites/0e1ef24a-927f-4094-bdaf-477e17c123b8/tokens/2b914582-17c3-42c5-b9e8-439816360a3e
```

Success is `204 No Content`. An unknown, already revoked, or unowned token
returns `404`; storage failures return `500`. Revoked tokens immediately stop
authenticating ingestion requests.
