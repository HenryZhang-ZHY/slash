Self Hosting is the complete operator path for running the Slash control plane.
It covers the server, Postgres, GitHub App credentials, optional user sign-in,
observability, credential rotation, and incident response.

## In this section

- [Deploy Slash](/en/self-host/deployment/) — start the server and Postgres,
  apply migrations, and verify the process.
- [Configure Slash](/en/self-host/configuration/) — set required variables,
  mount file-only secrets, and optionally enable GitHub user authentication.
- [Operate Slash](/en/self-host/operations/) — monitor queues, use the instance
  admin console, rotate credentials, and respond to incidents.

For product usage after the service is available, return to
[Run your first command](/en/getting-started/) or [Test Engine](/en/test-engine/).
