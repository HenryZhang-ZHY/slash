Slash is offered as a hosted cloud service. If you prefer to run it yourself —
on your own servers or your own cloud account — this section covers everything
involved: the reference deployment, environment configuration, observability,
key rotation, and incident procedure.

Self-hosting is a deliberate choice, not the default path. Most users never
need this section; it exists for teams that want full control over where the
Slash control plane runs.
