Slash 控制台从与 REST API 相同的 origin 提供账户、工作区、设置和 Test Engine 页面。
每个页面都通过有文档的 API 读取和更新服务端状态。

## 登录或注册

打开部署的控制台根路径。未认证访问会重定向到 `/login`，你可以：

- 使用邮箱和至少 8 个 Unicode 字符的密码创建账户；
- 登录已有密码账户；或
- 使用稳定的 GitHub 身份登录。

认证会创建 `HttpOnly` session cookie。Slash 不把 GitHub 邮箱当作身份主键，也不会
根据邮箱匹配来合并账户。如果已有密码账户，请先登录该账户，再从 Settings 连接
GitHub。

## 创建第一个团队

没有团队的用户会进入 `/onboarding`。输入团队名和由小写字母、数字、连字符组成、
最长 63 字符的 slug。创建第一个团队时，系统会在需要时创建 home organization，
并把你设为团队 maintainer。

团队用于组织 Test Engine suite 等 Slash 原生资源。谁能调用 slash command 则由
GitHub 仓库权限独立决定。

## 管理团队成员

从控制台导航的**团队**分组选择 Team，也可以从概览的团队列表进入。移动端导航提供相同
的 Team 入口。成员可以查看成员列表；maintainer 可以按邮箱邀请 member 或
maintainer、重新发送或撤销待接受邀请、调整角色和移除成员。Slash 始终保证至少保留一个
maintainer。

无论收件人已有 Slash 账户还是需要注册，邮件链接都能使用。登录后浏览器会返回邀请页，
由收件人确认接受。邀请七天后过期，并且只能使用一次。

## 使用控制台

概览把产品分为两个领域：用于仓库活动的**命令自动化**和用于测试智能的
**Test Engine**。页面还会显示测试汇总和你所管理团队的直接入口。
使用 [Test Engine 控制台](/zh-hans/test-engine/console/)创建 suites 并查看结果。

在 `/activity` 打开**命令活动**，可以查看已连接 GitHub 身份当前可读取仓库中的已接受
斜杠命令。授权、筛选与故障处理见
[查看命令活动](/zh-hans/commands/activity/)。

## 连接 GitHub

打开账户菜单并选择**账户设置**，或直接打开 `/settings`，查看与账户关联的 GitHub 身份。尚未关联时，可以从该页面开始连接
流程。Slash 根据认证后的 provider callback 解析连接结果，不信任浏览器 URL 参数。

## 管理密码

打开**账户设置**可以修改已有密码，或为目前只使用 GitHub 等外部身份的账户添加密码
登录。已有密码的用户必须输入当前密码；只有外部身份的用户需要选择一个唯一登录邮箱，
并设置至少八个字符的密码。

添加密码只会为同一个账户增加一种登录方式。Slash 不会把它与已经使用该邮箱的账户
合并。

## 管理 Personal Access Tokens

**账户设置**还允许为 Agent 和 REST API 客户端创建、吊销凭据。Token 以所属用户身份
认证，不会增加权限。明文只显示一次；之后列表只显示名称、创建时间、最近使用时间和
到期状态。

请求认证、有效期和吊销行为见
[Personal Access Token 参考](/zh-hans/api/access-tokens/)。

语言、外观、发布信息、账户设置和退出登录统一放在账户菜单中。这些是账户级控制，
不属于某个 Team 或 Test Engine suite。
