所有管理端点都需要有效的 `slash_session` cookie。套件和测试数据限定在拥有该套件的
账户范围内。属于不同账户的资源报 `404 Not Found`，而不是泄露它们的存在。

路径里的 ID 是 UUID。Test Engine JSON 字段使用 `snake_case`。

## GET `/api/test-engine/suites`

列出已认证账户的套件和聚合执行数。

```sh
curl -b cookies.txt \
  https://slash.example.com/api/test-engine/suites
```

成功：`200 OK`，带一个数组。

```json
[
  {
    "id": "0e1ef24a-927f-4094-bdaf-477e17c123b8",
    "suite_key": "ci-test",
    "owner": "acme",
    "repo": "checkout",
    "total_tests": 42,
    "muted": 2,
    "skipped": 1,
    "run_count": 18,
    "execution_count": 756,
    "passed_executions": 718,
    "failed_executions": 30,
    "skipped_executions": 6,
    "errored_executions": 2,
    "average_duration_ms": 83.4,
    "last_captured": "2026-08-12T04:00:00+00:00"
  }
]
```

在获得执行数据之前，`average_duration_ms` 和 `last_captured` 是 `null`。存储失败
返回 `500`。

## POST `/api/test-engine/suites`

创建套件，或当匹配套件已属于当前账户时复用它。套件存在后，再单独创建 collection
token。

```sh
curl -b cookies.txt \
  -H "Content-Type: application/json" \
  -d '{"owner":"acme","repo":"checkout","suite_key":"ci-test"}' \
  https://slash.example.com/api/test-engine/suites
```

三个字段都必填、会被 trim、并限制在 255 字节。

成功：`201 Created`。

```json
{
  "suite": {
    "id": "0e1ef24a-927f-4094-bdaf-477e17c123b8",
    "suite_key": "ci-test",
    "owner": "acme",
    "repo": "checkout",
    "total_tests": 0,
    "muted": 0,
    "skipped": 0,
    "run_count": 0,
    "execution_count": 0,
    "passed_executions": 0,
    "failed_executions": 0,
    "skipped_executions": 0,
    "errored_executions": 0,
    "average_duration_ms": null,
    "last_captured": null
  }
}
```

| 状态 | 含义 |
| --- | --- |
| `201` | 套件可用 |
| `401` | 无有效会话 |
| `409` | 另一个账户拥有匹配套件 |
| `422` | 某个必填字段为空或过长 |
| `500` | 套件持久化失败 |

## GET `/api/test-engine/suites/{id}/tests`

列出已拥有套件里的所有测试，包括当前处置状态、最近运行元数据和聚合执行数。

```sh
curl -b cookies.txt \
  https://slash.example.com/api/test-engine/suites/0e1ef24a-927f-4094-bdaf-477e17c123b8/tests
```

成功：`200 OK`，带一个数组。

```json
[
  {
    "id": "df5a68b4-bf9f-4745-a320-a7cd39b59249",
    "name": "checkout::completes_order",
    "state": "enabled",
    "state_source": "monitor",
    "state_reason": "failure-free reconciliation window",
    "state_changed_by_user_id": null,
    "state_changed_at": "2026-08-12T03:55:00+00:00",
    "file": "tests/checkout.rs",
    "line_no": 42,
    "labels": [],
    "owner_team_ids": [],
    "created_at": "2026-08-12T03:00:00+00:00",
    "updated_at": "2026-08-12T04:00:00+00:00",
    "last_status": "passed",
    "last_captured": "2026-08-12T04:00:00+00:00",
    "last_run_ref": "build/1842",
    "last_ci_provider": "buildkite",
    "execution_count": 18,
    "passed_count": 17,
    "failed_count": 1,
    "skipped_count": 0,
    "errored_count": 0,
    "average_duration_ms": 91.2
  }
]
```

`state_source` 为 `default`、`manual` 或 `monitor`。可选的状态 reason 和 actor
说明当前决策；最近运行和平均字段也可能是 `null`。未知或不拥有的套件返回 `404`；
存储失败返回 `500`。

## GET `/api/test-engine/suites/{id}/runs`

按从新到旧的顺序返回已拥有套件的一页运行，并包含每次运行的 execution 汇总。

| 查询参数 | 默认 | 行为 |
| --- | --- | --- |
| `limit` | `100` | 限制在 `1..200` |
| `offset` | `0` | 负值变成 `0` |

```sh
curl -b cookies.txt \
  "https://slash.example.com/api/test-engine/suites/0e1ef24a-927f-4094-bdaf-477e17c123b8/runs?limit=25&offset=0"
```

成功：`200 OK`。

```json
{
  "total": 18,
  "limit": 25,
  "offset": 0,
  "items": [
    {
      "id": "68e4a959-c699-4e32-9164-a4500ecfe26d",
      "run_ref": "build/1842",
      "ci_provider": "buildkite",
      "invocation_id": null,
      "started_at": "2026-08-12T03:59:00+00:00",
      "finished_at": null,
      "last_captured": "2026-08-12T04:00:00+00:00",
      "execution_count": 42,
      "passed_count": 39,
      "failed_count": 2,
      "skipped_count": 1,
      "errored_count": 0,
      "total_duration_ms": 3487
    }
  ]
}
```

`total_duration_ms` 是本次运行所有测试 execution 上报时长的总和。没有 execution 的
运行，其 `last_captured` 为 `null`。未知或不拥有的套件返回 `404`；存储失败返回
`500`。

## GET `/api/test-engine/runs/{id}/executions`

返回当前账户所拥有运行中采集到的一页测试。它的 `limit` 和 `offset` 有界行为与运行
列表相同。

```sh
curl -b cookies.txt \
  "https://slash.example.com/api/test-engine/runs/68e4a959-c699-4e32-9164-a4500ecfe26d/executions?limit=100&offset=0"
```

成功：`200 OK`。

```json
{
  "total": 42,
  "limit": 100,
  "offset": 0,
  "items": [
    {
      "id": "f8789438-fb99-45f6-a374-1335593264d1",
      "test_id": "df5a68b4-bf9f-4745-a320-a7cd39b59249",
      "test_name": "checkout::completes_order",
      "test_state": "enabled",
      "file": "tests/checkout.rs",
      "line_no": 42,
      "status": "passed",
      "duration_ms": 87,
      "stack": null,
      "captured_at": "2026-08-12T04:00:00+00:00"
    }
  ]
}
```

未知运行或不在账户已拥有套件里的运行返回空分页。存储失败返回 `500`。

返回属于当前账户的测试的一页最近执行历史。

| 查询参数 | 默认 | 行为 |
| --- | --- | --- |
| `limit` | `100` | 限制在 `1..200` |

```sh
curl -b cookies.txt \
  "https://slash.example.com/api/test-engine/tests/df5a68b4-bf9f-4745-a320-a7cd39b59249/executions?limit=25&offset=0"
```

成功：`200 OK`。

```json
{
  "total": 18,
  "limit": 25,
  "offset": 0,
  "items": [
    {
      "id": "f8789438-fb99-45f6-a374-1335593264d1",
      "status": "passed",
      "duration_ms": 87,
      "stack": null,
      "captured_at": "2026-08-12T04:00:00+00:00",
      "run_id": "68e4a959-c699-4e32-9164-a4500ecfe26d",
      "run_ref": "build/1842",
      "ci_provider": "buildkite",

      "finished_at": "2026-08-12T04:01:00+00:00",
```

## PATCH `/api/test-engine/tests/{id}/state`

改变测试的处置状态。

```sh
curl -b cookies.txt -X PATCH \
  -H "Content-Type: application/json" \
  -d '{"state":"muted","reason":"known provider instability"}' \
  https://slash.example.com/api/test-engine/tests/df5a68b4-bf9f-4745-a320-a7cd39b59249/state
```

允许的状态值是 `enabled`、`muted` 和 `skipped`。`reason` 是可选字符串。修改会记录为
手动决策，并把当前用户记录为 actor；自动 flaky reconcile 不会覆盖它。

成功：`200 OK`。

```json
{
  "state": "muted"
}
```

| 状态 | 含义 |
| --- | --- |
| `200` | 状态已改变 |
| `404` | 测试未知或不属于账户 |
| `409` | 状态更新输给了并发变更 |
| `422` | 请求的状态不受支持 |
| `500` | 所有权查找或更新失败 |

## GET `/api/test-engine/suites/{id}/tokens`

列出已拥有套件的非 secret token 元数据。此端点绝不会返回原始凭据。

```json
[
  {
    "id": "2b914582-17c3-42c5-b9e8-439816360a3e",
    "name": "Buildkite production",
    "status": "active",
    "created_at": "2026-08-22T06:00:00+00:00",
    "expires_at": null,
    "last_used_at": "2026-08-22T06:05:00+00:00",
    "revoked_at": null
  }
]
```

成功为 `200`。未知或不拥有的套件返回 `404`；存储失败返回 `500`。`status` 为
`active`、`expired` 或 `revoked`。永不过期的 token，其 `expires_at` 为 `null`。

## POST `/api/test-engine/suites/{id}/tokens`

为已拥有的套件签发一个只显示一次的 collection token。已有 token 会继续有效，因此
不同 CI 采集器可以使用各自命名的凭据，轮换也不会中断上传。

```sh
curl -b cookies.txt -X POST \
  -H "Content-Type: application/json" \
  -d '{"name":"Buildkite production","expires_at":null}' \
  https://slash.example.com/api/test-engine/suites/0e1ef24a-927f-4094-bdaf-477e17c123b8/tokens
```

`name` 必填、会被 trim，最长 100 个字符。`expires_at` 可以是表示永不过期的 `null`，
或未来的 RFC 3339 时间戳。省略 `expires_at` 也会创建永不过期的 token。

成功：`201 Created`。

```json
{
  "id": "2b914582-17c3-42c5-b9e8-439816360a3e",
  "name": "Buildkite production",
  "token": "new-collection-token-value",
  "expires_at": null
}
```

请立即复制响应中的原始 token；Slash 只保存哈希，无法再次显示它。未知或不拥有的
套件返回 `404`；无效名称或到期时间返回 `422`；签发失败返回 `500`。

## DELETE `/api/test-engine/suites/{suite_id}/tokens/{token_id}`

使用列表端点返回的元数据 id 吊销 collection token，不需要原始 secret。

```sh
curl -b cookies.txt -X DELETE \
  https://slash.example.com/api/test-engine/suites/0e1ef24a-927f-4094-bdaf-477e17c123b8/tokens/2b914582-17c3-42c5-b9e8-439816360a3e
```

成功为 `204 No Content`。未知、已吊销或不拥有的 token 返回 `404`；存储失败返回
`500`。被吊销的 token 立即停止认证 ingestion 请求。
