自托管是运行 Slash 控制面的完整运维路径，覆盖服务器、Postgres、GitHub App 凭据、
可选用户登录、可观测性、凭据轮换和故障响应。

## 本模块内容

- [部署 Slash](/zh-hans/self-host/deployment/) —— 启动服务器与 Postgres、执行迁移并
  验证进程。
- [配置 Slash](/zh-hans/self-host/configuration/) —— 设置必需变量、挂载仅文件 secret，
  并按需开启 GitHub 用户登录。
- [运维 Slash](/zh-hans/self-host/operations/) —— 监控队列、使用实例管理后台、轮换
  凭据并处理故障。

服务可用后，回到[运行第一条命令](/zh-hans/getting-started/)或
[Test Engine](/zh-hans/test-engine/)开始使用产品。
